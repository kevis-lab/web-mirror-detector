# Web Mirror Detector

Web Mirror Detector is a desktop application written in Python for detecting mirror and impersonation websites using visual similarity.

## Features

- Detects visually similar websites
- Generates domain permutations
- Supports multiple TLDs
- Captures screenshots
- Compares screenshots using perceptual hashing
- Exports results to Excel

## Technologies

- Python
- PyQt5
- aiohttp
- Pyppeteer
- Pillow
- imagehash
